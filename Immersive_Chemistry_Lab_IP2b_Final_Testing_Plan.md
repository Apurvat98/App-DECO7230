# **1\. Three-sentence project pitch**

Immersive Chemistry Lab is a VR experience in which players conduct three alchemy-themed chemistry activities: combining reactants, stirring a mixture and heating a flask. Pouring the reactants unlocks a circular portal that takes players into a molecular-scale environment to build and manipulate an H₂O molecule. The final prototype tests the discoverability of multiple spatial interactions, clear progression cues, feedback, and comfortable navigation on Meta Quest.

# **2\. Aim and IP2b contribution**

The test examines whether first-time users can start independently, complete the expanded multi-station experience, recognise visual prompts, trace the portal, construct and manipulate a molecule, and return safely to the lab. Unlike IP2a’s primarily pouring–expansion–molecule sequence, IP2b adds a circular controller-tracing transition, golden progress arc, return navigation, a spoon-stirring interaction, a flask-heating interaction, and clearer station guidance. The goal is usability and interaction quality, not measuring chemistry learning.

| Question / hypothesis | Observable evidence |
| :---- | :---- |
| **Can users tell where to start?** | Look toward welcome board, identify Experiment 01 without a prompt. |
| **Are object affordances and reach understandable?** | Grab bottles/spoon/flask without repeated misses; mention highlights or labels. |
| **Does the new portal gesture communicate progress?** | Discover circle tracing, notice gold trail, complete without full demonstration. |
| **Is molecular assembly and feedback clear?** | Connect two H atoms to O, recognise bond/completion feedback and optional bond stretching. |
| **Can people complete the other new interactions?** | Perform stirring and heating with minimal assistance. |
| **Is movement and return comfortable?** | Return with B, no height shift, obstruction, room-object bleed-through or discomfort. |

# **3\. Method, recruitment and timing**

Moderated, in-person Meta Quest task-based usability testing with concurrent think-aloud and brief follow-up questions. Aim for five or more classmates/tutors where possible (the brief allows fewer if data is actionable). Allow approximately 5 minutes per participant, with a longer session only if studio time permits. Record actual sample size and note the limitation of a convenience sample.

Use one recorder/facilitator, the same starting position and task prompts for each participant. Avoid revealing the solution. Use graduated prompting: P0 none; P1 general “Look around for a cue”; P2 contextual “What does that instruction suggest?”; P3 demonstration/physical help. Mark completion as Independent (I), Assisted (A), or Not completed (N). Record when an interaction was skipped because of time.

# **4\. Pre-test setup and safety**

• Save working APK and Unity project; confirm the Meta Quest build launches (do not substitute simulator testing).

• Disable XR Interaction Simulator in the device build; approve Quest connection/debugging if required.

• Clear real play area, check Guardian/boundary, headset fit and both controllers; offer a seated option if appropriate.

• At startup confirm normal eye height, facing direction, view of welcome board, table reachability and locomotion.

• Reset reactants, stir/heating states, portal, molecular atoms and completion feedback between sessions; restart app if reset is unreliable.

• If tracking, height, nausea or collision problems occur, stop immediately, help participant remove headset and log issue.

# **5\. Facilitator introduction (20–30 seconds)**

“Thank you for trying Immersive Chemistry Lab. Please explore the laboratory and try the activities using the instructions you find. Say aloud what you expect to happen or when you feel unsure. I’m testing the design, not you. You can stop at any time. I’ll only help if you get stuck.”

# **6\. Task sequence (target: about 5 minutes)**

| Time | Say to participant (do not reveal gesture) | Record |
| :---- | :---- | :---- |
| **0:00–0:35** | “Look around. Where would you start?” | Welcome sign noticed? Chosen first action? |
| **0:35–1:20** | “Start the first reaction with the equipment here.” | Grip, reach, both pours, result, help. |
| **1:20–2:00** | “Can you find a way to explore the molecules?” | Portal discovered? Circle trace and gold arc? |
| **2:00–3:10** | “Try making the water molecule. What does the feedback tell you?” | Snapping two bonds, H₂O feedback, optional stretch/break. |
| **3:10–3:40** | “Return to the laboratory and find another activity.” | B button, height stability, navigation. |
| **3:40–4:20** | “Try the stirring experiment.” | Spoon grab, stir gesture, completion cue. |
| **4:20–5:00** | “Try the heating experiment.” | Flask placement/rotation, effect, feedback. |

If a participant takes longer, prioritise first-use discovery, the new portal interaction, and at least one of the new stirring/heating tasks. Log any unattempted tasks as “Not tested”, NOT failures or successes. Do not silently skip the final activities across all participants.

# **7\. Observation measures and success thresholds**

| Measure | How recorded / target |
| :---- | :---- |
| **Task success** | I / A / N / Not tested; aim for majority I or A with only P1. |
| **Assistance** | P0–P3; specify exact intervention and where it occurred. |
| **Interface comprehension** | First action; did welcome board, highlight, portal ring, labels and feedback attract attention? |
| **Gesture reliability** | Portal trace completed? false starts/resets, distance or reach trouble. |
| **Comfort and safety** | Height instability, blocked route, collision, discomfort, tracking loss. |
| **Timing** | Approximate task time when feasible; not sole indicator of success. |
| **Experience connection** | Could participant explain that molecular scale relates to the reaction? |

# **8\. Follow-up prompts (30 seconds, choose 2–3)**

• Where did you first look for instructions?

• Which part felt least clear or hardest to control?

• Did the gold tracing trail and bond messages tell you what was happening?

• Did you feel comfortable with the scale change, movement and return?

• What single change would make the experience easier?

# **10\. DECO7230 research summary (required postgraduate paragraph)**

The testing approach is informed by research on 3D interaction, immersive usability and evaluation. Bowman et al. (2004) describe the demands of selection and manipulation in three-dimensional interfaces, supporting observation of grab distance, controller choice and object handling. Jerald (2015) places user-centred design, human factors and comfort at the centre of VR development, motivating explicit recording of reachability, orientation and physical discomfort. Sutcliffe and Gault (2004) show why virtual-environment evaluation should account for usability and presence together, supporting inspection of spatial cues, feedback and unexpected obstacles. Slater (2009) distinguishes place illusion and plausibility in immersive virtual environments, helping frame the question of whether movement between lab and molecular scale feels coherent. Brooke (1996) motivates brief, structured usability measurement; for this short studio test, repeatable task completion, assistance levels and post-task comments are collected rather than administering a long questionnaire. Collectively, these sources support a brief but systematic Quest-based evaluation of the interaction flow and the new features of IP2b.
